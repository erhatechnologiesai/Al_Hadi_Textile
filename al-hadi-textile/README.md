## 1. Project Overview & Brand Identity

This web application is built strictly according to the **AL HADI Execution Blueprint & Master Guide (`details.txt`)** and thorough industry benchmarking across premier international textile portals (*Tekla Fabrics, Linen Tales, The White Company, Brooklinen, Christy England*).

### 1.1 Brand Visual Identity
- **Primary Textile Orange (`#FF6B00`)**: Vibrant loom shuttle orange used for primary CTAs ("Order via WhatsApp"), notifications, and active filters.
- **Deep Slate / Carbon Charcoal (`#161B22`)**: Dark header bar, typography, and dark cards.
- **Warm Natural Cotton Canvas (`#F9F8F6`)**: Gentle warm unbleached cotton background avoiding harsh artificial white.
- **Woven Border Grey (`#E5E7EB`)**: Subtle card borders and specification dividers.
- **Forest Olive Accent (`#2D4030`)**: Organic linen and OEKO-TEX compliance badges.
- **Typography System**: Plus Jakarta Sans for bold headings and industrial authority; Inter for technical fabric tables and readable body text.

### 1.2 Human-Crafted Tone (Zero AI Fluff)
No empty marketing slogans ("Revolutionizing comfort", etc.). Instead, the application exclusively employs real, professional textile engineering terminology:
- *100% Ring-spun combed cotton*
- *280 GSM 3D Honeycomb waffle weave*
- *400TC Extra-long staple Egyptian cotton percale*
- *Yarn-dyed bistro checks & dobby headers*
- *Pre-washed and sanforized for <3% shrinkage*
- *Double-needle lockstitched hems & mitred 90° corners*

## 4. How to Run the Application

### 4.1 Running the Frontend
```bash
cd al-hadi-textile/frontend
npm run dev
# Or production build:
# npm run build
# npm run start
```
Frontend runs at: **`http://localhost:3000`**

### 4.2 Running the Backend REST API
```bash
cd al-hadi-textile/backend
node src/server.js
```
Backend runs at: **`http://localhost:5000`**

### 4.3 Running Both Concurrently
From the root workspace:
```bash
# Terminal 1: Backend
npm run dev:backend

# Terminal 2: Frontend
npm run dev
```

## 5. WhatsApp Direct Order & Lead Logging Flow

Every single Product Card, Modal, and Single Product page features an **"Order via WhatsApp"** button:

1. **Client Click**: When the user clicks the CTA, the frontend asynchronously fires `POST http://localhost:5000/api/inquiries`.
2. **Lead Tracking**: The backend controller records the product ID, name, quantity, client device, IP address, and timestamp into `leads.json`.
3. **WhatsApp Dispatch**: The user is immediately transitioned to WhatsApp (`https://wa.me/923001234567`) with the pre-filled inquiry text formatted exactly to specifications:

```
Salam AL HADI Textiles,
Mujhe is product ka order / rate confirm karna hai:

• Product: Charcoal Waffle Combed Cotton Dish Cloth Set (6-Pack)
• Category: Kitchen Linens
• Fabric: 100% Ring-Spun Combed Cotton (280 GSM)
• Size: 30 x 30 cm (12 x 12 in)
• Required Quantity: 5 piece(s)

Product Link: http://localhost:3000/products/charcoal-waffle-dishcloth-set

Meherbani karke wholesale / retail rate aur delivery details share karein.
```
